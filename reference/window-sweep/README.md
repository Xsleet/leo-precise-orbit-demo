# 无预热窗口长度实验归档

2019-01-02 00–07 时 GPS，八个固定窗口，预报 60 min。
8/12/24 h 拟合 × 1/2/4/6/8 h TimesFM 输入；原始模型，无微调。

- `gpu/`：全部 15 组合的预测坐标、参考坐标、逐点/逐窗口/整体评分、拟合参数和历史残差。本轮不重复运行完整 CPU 实验。
- `dynamics-cache/`：24 条由真实历史拟合得到的轨道，源码、数据和依赖版本必须匹配才复用。
- `benchmark/cpu/`、`benchmark/gpu/`：加载与首次调用耗时、三次稳定推理计时、实际预测输出与环境。
- `improvement.csv`：15 个组合相对各自动力学基线的变化及改善窗口数。
- `prefit.json`：动力学计算耗时（8 个并行工作进程，包含测速期间的暂停，不能当成单任务速度）；暂停记录见 `benchmark/pause.json`。
- `source/`：本次运行的源码快照；`validation.json`：哈希、权重标识及 CPU/GPU 差异。

数据和指标说明见 [RESULTS_WINDOWS.md](../../RESULTS_WINDOWS.md)。
最优组合由本组窗口比较得出，未在独立时段验证。原来的 2019 含预热和 2025 实验保持原样。
